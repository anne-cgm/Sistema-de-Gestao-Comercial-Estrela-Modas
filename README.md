# Sistema de Gestão Comercial

Sistema de gestão comercial desenvolvido para uma loja de roupas e acessórios, com foco no gerenciamento interno de produtos, estoque, vendas e demais operações administrativas.

O projeto tem como objetivo centralizar as informações da loja e reduzir a dependência de controles manuais, proporcionando maior organização dos dados e facilidade no acompanhamento das operações.

> **Status:** Em desenvolvimento
> **Tipo:** MVP — Sistema interno de gestão comercial

## 📌 Sobre o projeto

O sistema foi desenvolvido a partir do levantamento e da análise das necessidades de uma loja de roupas e acessórios.

A solução contempla, inicialmente, funcionalidades relacionadas ao cadastro de produtos, controle de estoque, registro de compras e vendas, gerenciamento de clientes, controle de débitos, trocas, despesas, dashboard e relatórios.

O projeto está sendo desenvolvido seguindo uma abordagem de desenvolvimento ágil, com levantamento e validação contínua dos requisitos junto às responsáveis pelo negócio.

## 🎯 Objetivos

* Centralizar as informações da loja em um único sistema;
* Facilitar o controle de produtos e estoque;
* Registrar vendas e compras de mercadorias;
* Auxiliar no acompanhamento de clientes e débitos;
* Registrar trocas e despesas;
* Disponibilizar informações gerenciais para acompanhamento do negócio;
* Reduzir a dependência de controles realizados manualmente.

## 📦 Funcionalidades do MVP

### Produtos

* Cadastro e gerenciamento de produtos;
* Organização por categorias;
* Cadastro de características e variações;
* Controle de preços;
* Identificação interna dos produtos por SKU e QR Code;
* Pesquisa e consulta de produtos.

### Estoque

* Consulta das quantidades disponíveis;
* Registro de entradas e saídas;
* Atualização automática do estoque;
* Identificação de produtos com estoque baixo.

### Registro de compras

* Registro de compras de mercadorias;
* Registro dos produtos e quantidades adquiridas;
* Registro dos valores das compras;
* Atualização do estoque após o recebimento das mercadorias.

### Vendas

* Registro de vendas;
* Registro dos produtos e quantidades comercializadas;
* Aplicação de descontos conforme as regras da loja;
* Registro da forma de pagamento;
* Atualização automática do estoque;
* Registro de vendas na modalidade fiado.

### Dashboard

* Acompanhamento das vendas;
* Visualização do estoque;
* Identificação de produtos com estoque baixo;
* Visualização de informações gerenciais.

### Clientes

* Cadastro de clientes;
* Consulta de dados;
* Histórico de compras.

### Clientes com débitos

* Consulta de clientes com valores pendentes;
* Consulta dos débitos;
* Registro de pagamentos;
* Atualização dos valores pendentes;
* Histórico de pagamentos;
* Controle de vendas realizadas na modalidade fiado.

### Trocas

* Registro de trocas;
* Atualização do estoque dos produtos envolvidos;
* Aplicação das regras de troca estabelecidas pela loja.

### Controle de despesas

* Registro de despesas;
* Consulta das despesas;
* Classificação das despesas conforme as categorias definidas para o negócio.

### Relatórios

* Informações consolidadas sobre vendas;
* Produtos mais vendidos;
* Produtos com estoque baixo;
* Indicadores financeiros definidos durante o levantamento de requisitos.

## 👥 Usuários do sistema

O sistema possui diferentes níveis de acesso, conforme as permissões estabelecidas para cada perfil.

### Administrador

Possui acesso às funcionalidades administrativas do sistema, conforme as permissões definidas para o negócio.

### Funcionário

Possui acesso às funcionalidades necessárias para a operação da loja, conforme as permissões estabelecidas pelas responsáveis pelo negócio.

# Integrações do Sistema

## 1. Comunicação Interna (Frontend <-> Backend)
- **Protocolo:** HTTP / HTTPS
- **Formato de Troca de Dados:** JSON
- **Padrão:** RESTful API

## 2. Serviços Externos / Infraestrutura
- **Automação (CI/CD):** GitHub Actions para validação e testes automatizados.
- **Hospedagem / Banco de Dados (Opcional):** Serviços em nuvem para deploy (ex.: Render, Railway ou Neon para PostgreSQL).
